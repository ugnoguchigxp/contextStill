UIスクリーンショット一覧

UI見直しの参照画像は assets/screenshots/ に保存する。実画面は撮影日ごとの YYYY-MM-DD/、画像生成によるUI提案は proposals/ に分ける。

現行UI：2026年9月20日撮影

認証後の通常画面13種類と設定7種類、計20画面を撮影した。互換URL /setting/distillation-runtime も含む21ルートを確認し、詳細・新規作成フォーム・表示切替・内部スクロールを合わせて54枚を保存した。全21ルートの初回撮影でAPIのHTTPエラーは検出されなかった。

表示サイズは1600×1000、device scale factorは1、ブラウザーはPlaywright Chromium。localhost:39171の開発サーバーを使用し、フロントエンドは作業ツリー（HEAD: 760476e2744cd4e6d964b6703da4af85df176bb9）、APIの画面内バージョン表示は context-still 0.1.0 (main@8a54cda)。既存のローカル実データを使用したため、撮影間で時刻・件数が変動する。設定の認証情報はUIのマスク表示のまま記録した。

通常はページ全体を保存し、固定高さの内部スクロール領域は追加画像で記録した。Landscapeは縦長の全体画像と先頭の表示領域を別々に保存した。詳細は代表項目のみで、全レコード・フィルターの全組み合わせ・モバイル幅・ログイン失敗状態は対象外。新規作成・編集フォームは表示のみで保存していない。

画面の正本は web/src/App.tsx。設定の distillation-runtime は Task Routing と同じ表示になる互換パス。/setting、/settings、/settings/$section はリダイレクト用のため独立画面には数えない。このリポジトリにはdeepStill専用ルートがなく、別アプリのdeepStill自体は今回の撮影対象に含めない。
